IDEMIA · Jun 2025 — Present · iOS lead & architect Featured

CryptoWallet iOS App & SDK

A hardware-wallet SDK and a SwiftUI wallet app for managing assets and signing transactions across Ethereum, Polygon and BSC, later taken to Android.

The challenge

Every app that used the hardware wallet had to handle low-level, chain-specific blockchain calls itself, and the app was making more server round-trips than it needed.

What I did

  • Designed a modular, plug-and-play iOS SDK that hides blockchain complexity behind one API
  • Wrote the app-to-server LLD, with request batching and a unified data flow
  • Built the SwiftUI asset and transaction flows, with real-time validation
  • Integrated JSON-RPC and Web3 for secure node communication
  • Extended the product to Android (Kotlin, Java, Room)
−40%network calls after the architecture redesign

Client: Infineon · Aug 2024 — Apr 2025

Digital Car Key: Secure Element Applet

Turning a phone into a car key requires cryptographic keys that never leave secure hardware and that comply with the Car Connectivity Consortium (CCC) specification.

  • Developed the JavaCard applet for secure key storage and cryptographic operations
  • Implemented GlobalPlatform SCP for authenticated, encrypted communication with the host
  • Handled key generation, mutual authentication and the full key lifecycle

OutcomeA CCC Digital Key–compliant applet for secure vehicle access

  • JavaCard
  • CCC Digital Key
  • GlobalPlatform SCP
  • Crypto
Independent research · Mar 2026 — Present Patent in preparation

Blockchain Identity for AI Agents

As AI agents start acting and paying on people's behalf, they need a verifiable identity. I'm designing one that is self-custodial and deterministic.

  • An identity standard built on HD wallet key derivation that extends existing agent-identity frameworks
  • A payment credentialing layer that links verified on-chain identity to traditional (Web2) payment systems
